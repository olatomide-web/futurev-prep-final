# Futurev Prep — AI BuildFest 2026 MVP

Futurev Prep is a focused WAEC Biology learning-assistant prototype for Track 4, Case Study 1: AI Education Access Assistant.

## MVP learning loop
Learn → Practice → Feedback → Learning-gap detection → Progress summary.

## Current demo scope
- Subject: WAEC Biology
- Topic: Photosynthesis
- 5-question practice session
- Immediate answer feedback
- Weak-area detection
- Session progress summary
- Responsive, text-first UI
- Session-only state via `sessionStorage`

## Run
Open `index.html` in a modern browser, or serve the folder with any static web server.

## Next integration
The UI and learning loop are deliberately separated from the AI provider. An API layer can later provide:
- topic explanations
- question generation
- answer evaluation
- personalized gap analysis
- targeted revision
